\# Data



The original EEG recordings and generated datasets are not included in this repository.



The original dataset contains EEG recordings from 140 participants:



\- 70 healthy participants

\- 70 participants diagnosed with an affective disorder



The dataset generation notebook expects the input EEG recordings and label file to be available locally.



The generated image datasets are also stored locally and are excluded from version control.



See `notebooks/dipl\_datasetovi.ipynb` for the dataset generation pipeline.
